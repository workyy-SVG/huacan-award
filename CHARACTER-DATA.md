# Character data sources

- Unihan 17.0.0, kTraditionalVariant and kSimplifiedVariant extracted from https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip. See unihan-license.txt.
- Hanzi Writer 3.5.0 from https://cdn.jsdelivr.net/npm/hanzi-writer@3.5.0/dist/hanzi-writer.min.js. See hanzi-writer-license.txt.
- Hanzi Writer Data 2.0.1, nine selected glyphs from https://github.com/chanind/hanzi-writer-data (Make Me a Hanzi, Arphic Technology). See arphic-license.txt.
- Dictionary definitions remain served by https://www.moedict.tw/.
