# 两岸新锐设计竞赛·华灿奖参赛项目

用于整理本团队的设计过程、作品源文件、展示内容和最终提交材料。

| 项目 | 内容 |
| --- | --- |
| 作品名称 | 待填写 |

| 团队成员及分工 | 待填写 |
| 指导教师 | 待填写（如适用） |
| 官方通知链接 | 待补充 |
| 提交截止时间 | 待核实，以官方通知为准 |

## 目录

- `docs/`：参赛要求、设计说明与提交检查清单。
- `research/`：调研资料、参考来源和分析记录。
- `design/`：草图、方案迭代与设计源文件。
- `assets/`：图片、字体等素材及其授权记录。
- `presentation/`：展板、演示文稿与展示视频。
- `submission/`：最终提交材料及版本记录。

## 开始使用

1. 核实官方通知，在 `docs/brief.md` 填写参赛要求。
2. 补全本页的项目信息，在 `docs/design-statement.md` 整理作品说明。
3. 按目录上传资料，通过 Issues 记录任务、负责人和截止时间。
4. 提交前核对 `docs/submission-checklist.md`，将确认版本放入 `submission/`。

## 文件约定

文件名建议采用 `作品名_内容_v01.扩展名`，便于识别版本。大型设计源文件和视频建议使用 Git LFS 或团队云盘，并在对应目录记录链接。

上传素材时记录来源与使用授权；个人证件、联系方式等报名信息通过比赛指定渠道提交。

本仓库为参赛作品管理空间，与赛事主办方无官方隶属关系。比赛要求以官方通知为准。
