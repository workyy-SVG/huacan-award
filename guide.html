使用说明

从一个汉字出发，探索两岸四海的生活印记。本作品以汉字、字形演变与民俗故事为线索，帮助用户发现不同地域之间的文化联系。

01快速开始

打开线上网址，等待首页加载。选择你的地区，或点击「同一个字，也有不同写法」进入精选寻踪。进入后可通过左侧功能区切换页面。

02精选寻踪

选择年、门、茶、船、灯、圆中的一个字。阅读字形观察与文化介绍，按页面提示观看字形演变、笔顺演示，再浏览不同地区的民俗案例。点击感兴趣的故事，阅读生活细节与文化联系。

03四海故事

点击左侧「四海故事」，按地区浏览案例。选择感兴趣的记录进入故事页，对照不同地方的生活习俗，再通过汉字切换入口继续探索。

04自由查字

点击「自由查字」，输入一个感兴趣的汉字并查询。查看字典释义、关联字形及可用的笔顺资料；六个精选汉字还可进入对应民俗故事。外部字典或在线查询服务可能受网络影响。

05我的寻踪卡

在故事页找到寻踪卡区域，选择想记住的生活记录并按页面提示保存。进入「我的寻踪卡」查看已保存的内容，点击回到故事可继续阅读。收藏保存在当前浏览器，清除浏览器数据或更换设备可能无法找回。

06资料与来源

进入故事后点击「资料与来源」，查看原文链接、文化资料及素材说明。建议结合原始出处阅读，区分史料、民俗记录与设计示意。

07简繁体与设备

在精选寻踪页面使用简繁体切换按钮，也可在首页选择地区。推荐使用最新版 Chrome、Edge 或 Safari 浏览器；电脑宽屏体验更完整。移动设备可滚动阅读，部分布局可能不同。

08线上访问与技术部署

普通用户无需下载或安装软件，直接打开 https://zili-xunzong.streamlit.app/ 即可体验。项目通过 GitHub 托管源代码与素材，Streamlit Community Cloud 从 gh-pages 分支读取 streamlit_app.py 并运行。开发者可获取该分支代码，在项目目录执行下方命令；在线查询功能可能还需要服务配置。

git clone -b gh-pages <仓库地址>
cd huacan-award
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py

打开线上作品

09常见问题

首次加载较慢时请等待云端启动；若页面异常，可刷新或稍后重试。查不到汉字时请确认只输入一个汉字，并尝试简繁体写法。收藏未显示时请确认使用同一浏览器，且未禁用本地存储。
