完整使用说明与常见问题

01快速开始

打开线上网址，等待首页加载。选择你的地区，或点击「同一个字，也有不同写法」进入精选寻踪。进入后可通过左侧功能区切换页面。

02精选寻踪

选择年、门、茶、船、灯、圆中的一个字。阅读字形观察与文化介绍，按页面提示观看字形演变、笔顺演示，再浏览不同地区的民俗案例。点击感兴趣的故事，阅读生活细节与文化联系。

03四海故事

点击左侧「四海故事」，按地区浏览案例。选择感兴趣的记录进入故事页，对照不同地方的生活习俗，再通过汉字切换入口继续探索。

04自由查字

点击「自由查字」，输入一个感兴趣的汉字并查询。查看字典释义、关联字形及可用的笔顺资料；六个精选汉字还可进入对应民俗故事。外部字典或在线查询服务可能受网络影响。

05我的寻踪卡

在故事页找到寻踪卡区域，选择想记住的生活记录并按页面提示保存。进入「我的寻踪卡」查看已保存的内容，点击回到故事可继续阅读。收藏保存在当前浏览器，清除浏览器数据或更换设备可能无法找回。

06资料与来源

进入故事后点击「资料与来源」，查看原文链接、文化资料及素材说明。建议结合原始出处阅读，区分史料、民俗记录与设计示意。

07简繁体与设备

可在自由查字中查看汉字的简繁关联字形，也可在首页选择地区浏览故事。推荐使用最新版 Chrome、Edge 或 Safari 浏览器；电脑宽屏体验更完整。移动设备可滚动阅读，部分布局可能不同。

08线上访问与技术部署

普通用户无需下载或安装软件，直接打开 https://zili-xunzong.streamlit.app/ 即可体验。项目通过 GitHub 托管源代码与素材，Streamlit Community Cloud 从 gh-pages 分支读取 streamlit_app.py 并运行。开发者可获取该分支代码，在项目目录执行下方命令；在线查询功能可能还需要服务配置。

git clone -b gh-pages <仓库地址>
cd huacan-award
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py

打开线上作品

09常见问题

首次加载较慢时请等待云端启动；若页面异常，可刷新或稍后重试。查不到汉字时请确认只输入一个汉字，并尝试简繁体写法。收藏未显示时请确认使用同一浏览器，且未禁用本地存储。

10寻踪小助手 · 语音朗读

点击右下角「寻踪小助手」，再点击「开始讲解」，即可按顺序朗读当前页面可见的正文。正在朗读的段落会高亮；可选择段落、暂停与继续、读下一段、停止或从头朗读，并调节语速、选择设备提供的中文声音。

拖动助手入口或面板标题，可在当前页面区域自由移动，切换页面后保留位置；点击「恢复默认位置」可回到右下角。入口聚焦后可用方向键微调、Home 键复位。收起面板后可继续收听，切换页面会停止。语音由阿里云百炼在云端合成，网页播放返回的音频，无需在电脑或手机上安装对应语言的系统声音。采用实时流式语音，前面的音频先播放，后面的继续生成。相邻短段会合并到同一连续朗读组，不再逐句等待完整音频文件；当前内容组会一起高亮。新内容仍有首次连接与缓冲时间，弱网时也可能停顿。服务器会缓存已生成的音频，缓存有效期最多 7 天。语言选项为中文普通话（Cherry）、香港澳门粤语（Kiki）及台湾台语／闽南语（Roy）。方言发音由模型生成，实际效果请试听，不保证所有地方用词与发音完全一致。可调节语速，播放中更改语速会从当前内容组重新开始。若服务报错，应检查百炼密钥权限、地域、qwen3-tts-flash 服务与额度；不会静默切回电脑系统声音。千问回答完成后，可点击回答旁的「朗读回答」，直接朗读该条回答，不重新改写。点击助手中的「从这里朗读」，再点击正文段落，可从该位置连续往下读；点击「朗读本页原文」可返回页面朗读。暂不支持麦克风语音指令。
